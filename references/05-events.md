# 本公司宏观、事件、催化与预期差

只保留能映射到本公司的利率、油价、美元、信用、行业CapEx、库存、监管与市场相对表现。
事件证据阶段：`研发设想 → 试点 → 产品可用 → 付费 → 约束合同 → 交付 → 收入 → 回款 → 稳定利润`，不能越级。
每个事件写首次披露/预计兑现时间、FACT/GUIDANCE等标签、改变哪个模型变量、是否有价格反应证据、验证失败怎么处理。
财报对照此前指引 / 同口径CONSENSUS / 本模型 / 实际与新指引；没有一致预期不称超市场预期。

## 条件事件与事件概率分开
“假设签下订单之后会怎样”不证明“订单将签下”。先记假设事件与已有事实，再做参与者反应；不要在模拟中创造订单，再引用它支持现实目标价。
同一事实对不同价格路径的解释，应检验此前是否计价、现有拥挤/流动性、兑现期限和资本需求。没有定量资金或交易结构，不把发帖数量、情绪分数转换成涨幅。
事实/指引修订、关键里程碑失效、融资方案变化或数据纠错时，更新状态和对应变量；只有观点重复不机械重算全部模型。
